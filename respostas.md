# ExercicioWeb

# Questão 1: 
a) Será exibido a frase "Menor de idade", pois o número 16 é menor que 18. 

b) Para ser exibida a frase "Maior de idade", o valor da variável idade precisa ser alterado para um número que seja igual ou maior que 18.  

# Questão 2: 
a) Quando o usuário clica no botão de login em um site, os dados informados são enviados para o sistema, que verifica se estão corretos. Se estiverem, o usuário consegue fazer login e acessar a próxima tela. 

b) Os usuários de um sistema ficam armazenados em um banco de dados, onde ficam salvas as informações.
